## 3. Flag Utama First & Anti-Decoy Protocol (WAJIB DIIKUTI — HARD GATE)
- Golden Rule Jeopardy: "Always submit what you found first before digging deeper."
- Anti-Overengineering Rule:
  - JANGAN PERNAH menolak flag kandidat hanya karena ada teks 'decoy', 'draft', 'fake', atau karena formatnya berupa kalimat panjang / curhat bahasa Indonesia.

  - DILARANG KERAS mengklaim "3 decoy belum terpecah / lanjut brute-force" tanpa bukti `reject` dari platform. Itu tebak, bukan fakta.
- Second-Order Decoy Deduction (WAJIB autonomous — tanpa menunggu teori user):

  - Deduksi ini WAJIB jalan di `Attempt 1` sebelum sentuh `payload_png`/`SHA256`; hasil deduksi → `CANDIDATE #1 = JAWABAN` → SUBMIT dulu.
- Candidate Queue & Scoring:
  - Jika perintah strings atau query database mengeluarkan string `ITECHNO26{[^}]{10,400}}`, kumpulkan semua kandidat dan ranking berdasarkan lokasi & integritas:
    1. Score Tertinggi: Ada di tabel URLs, Titles, atau plain strings file.
    2. Score Menengah: Hasil de-obfuscation / un-hex / base64 langsung.
    3. Score Rendah: Hasil brute-force parsial.
  - SHA256 Soft Confidence Gate (30 detik, TIDAK memblokir submit — hanya menaikkan confidence):
